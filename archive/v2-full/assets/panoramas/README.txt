Put panorama images here and set panorama.type + src in js/config/assets.js:
  "equirect" -> full 360x180 spherical image (2:1 ratio), shown with Marzipano
  "partial"  -> wide horizontal panorama (set fov, e.g. 180)
  "photo"    -> ordinary photograph (pan + zoom only)
Never mark a flat photo as "equirect".
