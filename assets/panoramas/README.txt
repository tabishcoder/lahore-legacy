Your panoramas go here (e.g. iPhone Camera > Pano).

1. Export as JPG, about 6000 px wide or smaller (keeps the site fast).
2. Name it simply: badshahi.jpg, fort.jpg, minar.jpg, park.jpg, wazir.jpg, shalimar.jpg
3. In js/config/assets.js set the place's pano, e.g.
     pano: { src: "assets/panoramas/badshahi.jpg", by: "Shoaib Mushtaq" },
That's it: the virtual tour shows it first, labelled "Panorama".
(An iPhone Pano is a wide photo, not a 360° sphere, so it is never called 360°.)
